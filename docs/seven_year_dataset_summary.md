# Seven-Year Dataset Summary

## Historical Date Range

- Existing dataset generated by `restaurant-backend/database/seeders/ProductionDataSeeder.php`
- Generation window used by the seeder: `now()->subYears(7)` through `now()`
- Observed order creation range: 2019-10-24 through 2026-10-27
- Observed reservation date range: 2019-10-31 through 2026-11-23
- Observed payment creation range: 2019 through 2026
- The existing dataset is a rolling seven-year dataset, not the exact calendar range 2019-01-01 through 2025-12-31.
- All generated records are synthetic test data and must not be represented as real historical business transactions.

## Dataset Characteristics

- Includes ordinary business days, weekends, and a date span covering 2019 through 2026.
- Includes dine-in, takeaway, and delivery order types.
- Includes multiple payment methods for completed orders.
- Includes inventory purchases, stock movements, adjustments, and wastage.
- Includes employee profiles, schedules, and limited attendance records.
- Does not include kitchen tickets, refunds, wastage records, waitlist records, gift cards, cash-register sessions, replenishment requests, or hotel records.
- Does not include complete calendar-year coverage for 2019-2025.

## Records Rejected or Prevented

- No records were generated during this audit, so no new rejection count applies.
- The existing seeder is destructive and truncates relevant tables before regeneration; it is not idempotent for the main dataset.
- Deterministic UUIDs are used for major entities, reducing accidental duplicate identifiers on rerun.

## Remaining Data Issues

- Historical order totals use VAT-exclusive arithmetic while the application setting is VAT-inclusive.
- Customer aggregates are randomly generated and do not derive from orders.
- Customer classification values used by reports are not stored in the database.
- Reservation end times cannot represent late-night wraparound because `end_time` is time-only.
- Inventory sign conventions and opening stock are not represented consistently.
- Historical coverage is rolling rather than the exact calendar years 2019-2025.
